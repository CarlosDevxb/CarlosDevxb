# ¡Hola, mundo! 👋 Soy José Carlos (CarlosDevxb)

Soy un **Ingeniero en Sistemas Computacionales** y Desarrollador Full-Stack apasionado por la arquitectura de software, el desarrollo de aplicaciones seguras y la gestión de infraestructuras cloud. Actualmente me desempeño como Coordinador Técnico y Fundador de **Cuchipu Cloud**, donde lidero el desarrollo de soluciones escalables, infraestructura y despliegues a medida.

---

## 👨‍💻 Sobre Mí

* 🚀 Me especializo en el ecosistema JavaScript/TypeScript, construyendo interfaces dinámicas con **React, Angular y Astro**, respaldadas por backends robustos en **Node.js, Express y Go**.
* ☁️ Diseño y administro infraestructuras modernas: desde la contenerización con **Docker y Docker Compose** hasta pipelines de CI/CD con **GitHub Actions** en plataformas como **AWS y Microsoft Azure**.
* 🗄️ Tengo un fuerte enfoque en la arquitectura de bases de datos relacionales (**MySQL, PostgreSQL/PostGIS**) y en el desarrollo seguro de aplicaciones con control de accesos basado en roles (RBAC) y JWT.
* ⚙️ Poseo experiencia avanzada en la administración de servidores Linux (Ubuntu Server, Fedora, Mint), redes Cisco, virtualización y configuraciones multi-boot.
* 🤖 Integro herramientas de IA en mi flujo de trabajo para optimizar la creación de prototipos, auditoría de código y producción de arquitecturas.

## 🚀 Proyectos Destacados

* ☁️ **Cuchipu Cloud:** Servicios de desarrollo web a medida, soluciones cloud y gestión de infraestructura tecnológica.
* 🏥 **MediTec-ITS:** Plataforma integral para la gestión médica y de enfermería en entornos educativos, con modelado de bases de datos relacionales e interfaces escalables.
* 🔬 **CuchiLab:** Sistema de gestión de inventarios y soporte de equipos para laboratorios de arquitectura de computadoras.
* 🚌 **Plataforma de Tránsito Público:** Aplicación web con PostGIS para la visualización de rutas y seguimiento de tarjetas de transporte.
* ⚙️ **Automatización Empresarial (Valy Bordados):** Herramientas de administración personalizadas, scripts de seguimiento de folios y control de inventarios mediante Google Apps Script.
